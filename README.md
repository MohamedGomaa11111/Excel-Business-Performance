# 📈 Advanced Excel Sales Performance Analytics

A comprehensive business analysis project built entirely using Microsoft Excel, showcasing advanced data manipulation, dynamic calculations, and executive reporting techniques.

## 📌 Project Overview
This project focuses on processing raw sales data, building structured tables, utilizing advanced Excel functions/formulas, and summarizing business metrics to support data-driven decision-making.

## 🛠️ Key Skills & Features Demonstrated
- **Data Cleaning & Preparation:** Handled raw data, removed duplicates, and formatted types correctly.
- **Advanced Formulas & Functions:** Implemented complex lookups, logical functions, and aggregations.
- **Pivot Tables & Charts:** Created dynamic Pivot Tables and interactive visual charts to track trends.
- **Executive Summary:** Designed a clean reporting layout for business stakeholders.

## 📁 Repository Files
- `TECHNEST_Sales_Performance_H1_2026.xlsx`: The main Excel workbook containing raw data, analysis, and reports.
